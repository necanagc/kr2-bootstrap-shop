# Контрольная работа №2

Тема: «CSS-фреймворки: разработка интерфейса на Bootstrap или альтернативном CSS-фреймворке».

## Описание

«Муз-Раб» — шуточный каталог музыкантов для группы: здесь можно выбрать басиста, гитариста, барабанщика или вокалистку и оставить заявку. Интерфейс построен на Bootstrap и оформлен в тёплой оранжево-коралловой палитре.

## Практическая работа 9

Выполнена главная страница на Bootstrap-сетке.

Реализовано:

- подключение Bootstrap через CDN;
- подключение `css/custom.css`;
- шапка страницы;
- Bootstrap-навигация;
- hero-блок на сетке;
- блок преимуществ;
- адаптивная витрина музыкантов с фотографиями;
- подвал на каждой странице.

## Используемые технологии

- HTML;
- Bootstrap;
- CSS;
- Git;
- GitHub.

## Практическая работа 10

Тема: «Страница на Bootstrap: компоненты».

Выполнено:

- добавлена единая Bootstrap-навигация;
- создана страница каталога `catalog.html`;
- создана страница товара `product.html`;
- создана страница заявки `order.html`;
- используются компоненты `navbar`, `card`, `btn`, `badge`, `alert`, `form-control`, `input-group`, `form-check`, `accordion`;
- карточка музыканта открывается с параметром `product.html?id=...`, по которому показываются соответствующие фото, описание и цена;
- кнопка заявки передаёт выбранного музыканта в форму;
- изображения музыкантов хранятся в `images/`;
- файл `css/custom.css` задаёт палитру и стили проекта;
- проект подготовлен к сдаче контрольной работы №2.
